Responsive CSS Cheat Sheet

Important concepts of responsive web design

CSS Filters

CSS filters change the appearance of images.

filter: grayscale(100%);

Media Queries

Media queries apply styles based on screen size.

@media (max-width: 700px)

Responsive Design

Responsive design makes websites adapt to different devices.

width: 100%;

Typography

Responsive typography adjusts text size according to the screen width.

font-size: clamp(1rem, 2vw, 1.5rem);

CSS Grid

Grid creates rows and columns for layouts.

display: grid;

Flexbox

Flexbox arranges elements in a flexible layout.

display: flex;
