Responsive Design Concepts

Learn the basic principles of responsive websites

Fluid Layouts

Fluid layouts use flexible widths such as percentages instead of fixed pixel values. 

.container {
    width: 90%;
}

Flexible Media

Flexible media allows images and videos to resize according to the screen width. 

img {
    max-width: 100%;
    height: auto;
}

Breakpoints

Breakpoints are screen sizes where the website layout changes using media queries. 

@media (max-width: 600px) {
    body {
        font-size: 14px;
    }
}
