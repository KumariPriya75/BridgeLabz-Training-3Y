# JavaScript Assignment 3

Each question has a separate HTML file and JavaScript file (`q1.html` + `q1.js` through `q10.html` + `q10.js`).

## How to run
1. Extract the `javascript-assignment3.zip` file.
2. Open the `javascript-assignment3` folder in VS Code.
3. Open any `qN.html` file in a browser (Live Server is optional).
4. Press F12 and open the Console tab to see `console.log()` output.
5. Q6 asks for a pyramid height; press Cancel or leave it blank to use the default height of 5.

## Debugging tasks
For questions that ask for breakpoints, open the relevant `.js` file in VS Code, click beside a line number to add a breakpoint, then press F5 and choose a browser/debug configuration if available. You can also use browser DevTools → Sources to set breakpoints, watch variables, and inspect the Call Stack.

All JavaScript files use strict mode where applicable and include explanatory comments.
